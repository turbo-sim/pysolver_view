# PySolverView documentation

PySolverView provides a common interface and convergence histories for
optimization and nonlinear equation solving with SciPy and custom solvers.

Start with [installation](introduction.md), then follow the
[optimization tutorial](tutorial_optimization.md) or the
[nonlinear systems tutorial](tutorial_nonlinear_system.md).
The [source layout guide](source_layout.md) explains canonical imports,
compatibility exports, and optional dependencies.
